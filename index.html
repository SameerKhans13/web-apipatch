Command-Line Workflow

Simple, safe commands following plan-before-apply principles.

1. Observation
apipatch scan --all
Inspect dependencies, contracts, and security advisories in read-only mode.
2. Simulation
apipatch plan --strategy minor
Generate an inspectable, non-breaking upgrade plan without modifying files.
3. Remediation
apipatch apply --all --yes
Apply verified codemods, update manifests, and run compiler gates.
